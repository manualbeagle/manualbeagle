Batch

A list of things you own: CSV with brand and model columns (name optional), or YAML. The file is read here in the browser; only its text is sent to Manual Beagle.

Homebox

Sync

For every item with a manufacturer and model but no manual: find it, download it into the library and check its text. The dry run writes nothing to Homebox; you then choose to attach the results.

Import from Home Assistant

Reads Home Assistant's devices (it changes nothing there) and offers those Homebox doesn't have as new items, each in its area as the location. Services such as the sun, helpers, disabled devices and a second device of the same model are skipped. Nothing is added until you say so, one item or all of them.

Maintenance

Tasks with an interval read from the manuals in the library, such as “clean the filter every 2 weeks”, each with the page it came from. Nothing is filed until you add it: an added task becomes a maintenance entry on its Homebox item for the date you choose, or, when Settings sends approved maintenance to Donetick, a chore that repeats on the task's interval from that date. A dismissed task isn't suggested again.

Settings

A change here is saved beside the library and used at once; it wins over the config file. Use the file's value takes a change away. API keys, and where the server reads them from, stay in the config file or the server's environment.
